# 串口(USB) 配置指南

设备支持两种配网方式：**蓝牙(BLE)** 和 **USB 串口**。两者在「配置模式」下同时可用，谁先保存生效。

## 关键：串口什么时候能连上

设备为了省电，大部分时间处于 deep sleep。deep sleep 时 ESP32-S3 的 USB-Serial-JTAG 会断电，电脑上的 COM 口会直接消失。

因此：

- **串口只在「配置模式」下保持连接。**
- 配置完成（`save`）后设备会联网刷新，然后进入 deep sleep，串口断连——**这是正常现象，不是故障**。

## 如何进入配置模式（让串口保持连接）

| 场景 | 操作 |
|---|---|
| 首次上电 / NVS 里没有有效配置 | 自动进入配置模式，屏幕显示 `SETUP` |
| 已有配置、设备在睡觉 | **按住板上的 BOOT 键**唤醒，直接进入配置模式 |

> 不要按住 BOOT 去按复位键——GPIO0 同时是 ESP32-S3 的下载模式 strap，那样会进下载模式而不是配置模式。

进入配置模式后，屏幕显示 `SETUP` / `USB SERIAL OR BLE`，此时串口和蓝牙都保持常开。

## 不修改配置，直接退出

如果设备已经保存过有效配置，SETUP 屏幕底部会显示 `HOLD BOOT: EXIT`。先松开
进入 SETUP 时按下的 **BOOT**，然后再次长按 **BOOT 2 秒**，即可放弃本次尚未
保存的修改、重新加载 NVS 中的原配置并继续联网刷新。

首次启动且没有有效配置时不能用 BOOT 跳过，必须先通过 BLE 或串口完成配置。

## 串口命令

配置模式下，用任意串口终端（115200 8N1）连接 USB 口，输入命令：

| 命令 | 作用 |
|---|---|
| `help` | 列出所有命令 |
| `show` | 打印当前待保存配置（密码和 API key 打码） |
| `ssid <文本>` | 设置 Wi-Fi SSID |
| `pass <文本>` | 设置 Wi-Fi 密码 |
| `apikey <文本>` | 设置 Tako API key |
| `interval <分钟>` | 设置刷新间隔（1..10080） |
| `save` | 校验并写入 NVS，随后自动联网刷新 |

命令大小写不敏感；`show` 里密码/API key 只显示前两位，其余用 `*` 遮盖。

## 配置步骤示例

1. 按住 BOOT 唤醒（或首次上电），屏幕出现 `SETUP`。
2. 确认电脑识别出串口：设备名是 `USB JTAG/serial debug unit`（通常 COM19，不同机器可能不同）。
3. 打开串口工具，例如 `idf.py -p COM19 monitor`，或 PuTTY/其他终端（115200）。
4. 依次输入：
   ```
   ssid MyWifi
   pass mypassword
   apikey sk-xxxx
   interval 60
   show
   save
   ```
5. 看到 `saved` 后，设备自动联网 → 拉取配额 → 刷屏 → deep sleep，串口随即断连（正常）。

## 串口断连后想再次操作

再次**按住 BOOT 键**唤醒设备，即可重新进入配置模式，串口会重新枚举出来。

## 注意事项

- 使用**数据线**，纯充电线没有数据通路，不会出现 COM 口。
- 蓝牙与串口可同时使用；两个通道谁先 `save` 谁生效。
- 实测本板（V2）电池电量显示在底部 UPDATED 栏右侧，无电池（纯 USB 供电）时不显示。
